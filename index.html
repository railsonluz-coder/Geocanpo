Levar os pontos para o QGIS

—

O pacote reúne pontos.csv, pontos.geojson e a pasta fotos. Pelo menu de compartilhar você escolhe AirDrop, Arquivos ou iCloud.

No QGIS

  1. Descompacte o .zip numa pasta.
  2. Arraste o arquivo pontos.geojson para o QGIS. O sistema de coordenadas é o WGS 84 (EPSG:4326).
  3. Para reprojetar para a grade, use SIRGAS 2000 / Brazil Polyconic (EPSG:5880).
  4. Os campos têm os mesmos nomes do projeto do QField, então os dois conjuntos de pontos podem ser unidos.
